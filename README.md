# 🛡️ FormGuard AI

> **Automated Formal Verification for Python Logic using Z3 SMT Solver.**

FormGuard AI is a lightweight formal verification dashboard designed to detect critical logic flaws, edge-case vulnerabilities, and invariant violations in executable code prior to runtime deployment.

---

## 🚀 Features

- **Symbolic Execution:** Powered by Microsoft Research's **Z3 SMT Solver**.
- **Dynamic Logic Parsing:** Express input expressions and security invariants on the fly.
- **Counterexample Generation:** Instantly outputs exact input vectors that trigger invariant violations (SAT status).
- **Interactive Web Interface:** Clean Flask + HTML/JS dashboard with real-time feedback.

---

## 🛠️ Tech Stack

- **Core Engine:** Python 3.x, `z3-solver`
- **Backend API:** Flask, `flask-cors`
- **Frontend:** Vanilla HTML5, CSS3, JavaScript (Fetch API)
